# Simple Calculator 🧮

## About
This is my first basic Python project. It is a simple calculator that performs four basic mathematical operations.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Handles division by zero
- Handles invalid operators

## Concepts I Practised
- Variables
- User input
- Float data type
- Type conversion
- Conditional statements (if, elif, else)
- Comparison operators
- Arithmetic operators

## How to Run
1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Run the following command in the terminal:

   python calculator.py

## Language Used
- Python 🐍

## What I Learned
Through this project, I practised Python fundamentals and learned how to combine variables, user input, conditional statements, and operators to build a simple working program.
